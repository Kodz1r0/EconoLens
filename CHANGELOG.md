# Changelog

## 0.1.0 — October 2026

- MVP web app: basket builder, personal inflation, salary and purchasing power, forecast, scenarios, RU/UZ/EN explanations.
- Official CPI data by 13 divisions, Aug 2024 – Sep 2026, rebuilt from 14 stat.uz releases with automatic consistency checks.
- Estimated official basket weights for 2026.
- Forecast with walk-forward backtest against naive baselines.
- Unit tests and GitHub Actions workflow.
